# Orchid Tracker Documentation

Welcome to the official technical documentation for **Botanical Archivist (Orchid Tracker)**[cite: 1]. Orchid Tracker is a desktop application designed to provide a calm, dark-themed interface for managing specimen inventory ledgers, tracking bloom cycles, logging hydration and potting media changes, and preserving historical archives[cite: 8].
